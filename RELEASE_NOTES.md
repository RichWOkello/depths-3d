# DEPTHS 3D v6.0.0 — The Bestiary Expansion

**Release date:** 7 November 2026  
**Repository:** https://github.com/RichWOkello/depths-3d  
**Play:** https://richwokello.github.io/depths-3d/  
**Author:** Richard Okello

This version consolidates the complete set of game changes developed through November 7 into one unified release. It includes redesigned dungeon/portal effects, combat and progression improvements, interface and audio refinements, and a procedural six-species horror bestiary. The latest approved Necromancer and the more detailed Flesh Brute, Crypt Crawler, Flesh Imp, Gaunt Hooded Wraith and Winged Gargoyle are included.

### Highlights
- Themed portals and richer dungeon environments.
- Eight existing weapons; enhanced handling and combat features.
- Perks, armour, relic bonuses, save compatibility and Soul Forge steps.
- Redesigned monster silhouettes, facial anatomy, materials and monster-specific animation.
- Browser, Colab and interactive creature-comparison viewer from one source of truth.

### Quality notes
Automated syntax and simulation checks are distinct from true GPU/WebGL validation. Visual reference likeness, skeletal sophistication, sustained 60 FPS and real Colab playback have not been certified. Procedural models remain approximations. See `TEST_REPORT.md`.

### Upgrade
Preserve the existing Git repo and history, extract the ZIP into your local `depths-3d` folder, replace matching files, commit, push `main`, then create tag `v6.0.0`. Instructions: `UPDATE_LOCAL_REPO.md`.
